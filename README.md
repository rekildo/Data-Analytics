# Data Analytics Portfolio

This repository is a collection of end-to-end data analytics projects that I've built from scratch, covering the full workflow from raw data to business insights — using **Power BI**, **SQL**, and **Python**.

## 🔍 What's Inside

- **Data Cleaning & Preparation** — handling raw, messy datasets and transforming them into analysis-ready formats
- **Exploratory Data Analysis (EDA)** — using Python (Pandas, NumPy, Matplotlib/Seaborn) to uncover patterns, trends, and insights
- **Power BI Dashboards** — interactive reports with DAX measures, data modeling, and business-focused visualizations
- **SQL** — queries for data extraction, transformation, and analysis
